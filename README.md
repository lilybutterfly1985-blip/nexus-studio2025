# Nexus Studio — 50+ Module Production Build

A modular digital-product marketplace monorepo.

## Included
- Next.js-style web application structure
- TypeScript API/domain modules
- Prisma/PostgreSQL schema
- Shared configuration and UI
- 50+ domain modules
- Tests and operational documentation

## Run
Install dependencies with pnpm, configure `.env`, start PostgreSQL, then run the workspace.
